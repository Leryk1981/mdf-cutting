# MDF Cutting

Локальная программа раскроя MDF с браузерным SVG-редактором карт. Интерфейс
объединяет запуск расчёта, ручное перемещение и поворот деталей, перенос между
картами, фиксацию, повторную упаковку и проверку последовательности из одного,
двух или трёх гильотинных резов. Все полученные прямоугольные остатки связаны с
тем же планом и передаются в обновлённую таблицу склада.

## Запуск

```powershell
.\.venv\Scripts\python.exe main.py
```

Программа запускает локальный сервер только на `127.0.0.1` и открывает страницу
`http://127.0.0.1:8765` в браузере. Исходные CSV и папка результатов выбираются
на стартовом экране. Параметр узоров оператору не требуется.

Старый интерфейс сохранён как резервный вариант:

```powershell
.\.venv\Scripts\python.exe main.py --legacy-tk
```
