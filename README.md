# MDF Cutting

Локальная программа раскроя MDF с браузерным SVG-редактором карт. Интерфейс
объединяет запуск расчёта, ручное перемещение и поворот деталей, перенос между
картами, фиксацию, повторную упаковку и проверку последовательности из одного,
двух или трёх гильотинных резов. Все полученные прямоугольные остатки связаны с
тем же планом и передаются в обновлённую таблицу склада.

## Установка и запуск

Требуется Python 3.12 или новее. Один раз в папке программы выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Затем запускайте программу командой:

```powershell
.\.venv\Scripts\python.exe main.py
```

Программа запускает локальный сервер только на `127.0.0.1` и открывает страницу
`http://127.0.0.1:8765` в браузере. Исходные CSV и папка результатов выбираются
на стартовом экране. Программа не содержит производственных таблиц: оператор
всегда выбирает актуальные файлы заказа и склада вручную.

Пошаговый производственный сценарий описан в
[руководстве оператора](docs/operator-review-guide.md).
