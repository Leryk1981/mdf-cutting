# MDF Cutting

Локальная программа раскроя MDF с браузерным SVG-редактором карт. Интерфейс
объединяет запуск расчёта, ручное перемещение и поворот деталей, перенос между
картами, фиксацию, повторную упаковку и проверку последовательности из одного,
двух или трёх гильотинных резов. Все полученные прямоугольные остатки связаны с
тем же планом и передаются в обновлённую таблицу склада.

## Установка для оператора

Скачайте `MDF Cutting Setup 1.0.0.exe` со страницы релиза и запустите установщик.
Он создаст ярлык на рабочем столе. После установки запускайте
**MDF Cutting** ярлыком с рабочего стола или из меню «Пуск». Python, GitHub и
командная строка оператору не нужны.

Программа открывает рабочее окно в браузере, но работает только локально на
`127.0.0.1`: интернет не требуется, данные не покидают компьютер.

## Сборка установщика

Для сборки из исходного кода требуется Python 3.12, PyInstaller и Inno Setup.
После установки зависимостей выполните:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\scripts\build_windows.ps1
```

Готовый файл появится в `artifacts\MDF Cutting Setup 1.0.0.exe`.

Пошаговый производственный сценарий описан в
[руководстве оператора](docs/operator-review-guide.md).
